## Cosmas 1.2.2 Beta

Cosmas now finds your recordings even when you don't use Medal.

### New
- **Recording folders of other programs are offered**: OBS Studio (read from its own settings), NVIDIA ShadowPlay /
  NVIDIA App, Xbox Game Bar, AMD Radeon ReLive and Outplayed (Overwolf). The overview shows the folders it found with
  the number of recordings in them; tick the ones you want and click *Add selected*. They are also listed in
  **Settings → Library → Found on this PC**. Nothing is added without you – a folder that is your whole Videos folder
  says so, because films and other videos in it would be catalogued too.
- **More formats**: besides mp4, mkv, mov and webm, the library now reads **m4v, ts, flv and avi** (a file with one of
  these extensions is added only when it really is a video – `.ts` is also used by TypeScript, for example).

### Fixed
- Medal folders are found in the Windows **Videos folder wherever it is** (e.g. moved to another drive), and `X:\Medal`
  on every drive, not only C–H.
